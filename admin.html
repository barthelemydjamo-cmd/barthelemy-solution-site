Configuration nécessaire

Cette administration utilise Supabase pour une authentification réelle. Pour l’activer, renseignez les paramètres dans config.js, exécutez le script supabase-setup.sql dans votre projet Supabase et créez votre compte propriétaire. Ne mettez jamais une clé service_role dans le site.

Sans cette configuration, la connexion ne peut pas fonctionner et aucun contenu ne sera modifiable depuis cette page.

Paramètres de sécurité et confidentialité
